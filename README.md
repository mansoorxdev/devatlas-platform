# DevAtlas Platform Workspace

This is the monorepo root workspace for DevAtlas platform.

## Structure
- [client](file:///c:/Users/manso/OneDrive/Desktop/devatlas-platform/client): Frontend Single Page Application built with React 19, Vite, and Tailwind CSS v4.
- [server](file:///c:/Users/manso/OneDrive/Desktop/devatlas-platform/server): Backend API server built with Node.js, Express, and MongoDB.

## Getting Started

### Installation
Run the following command in the root folder to install all dependencies for both workspace projects:
```bash
npm install
```

### Running in Development Mode
Run the development servers for both client and server concurrently:
```bash
npm run dev
```

Or run them individually:
* Client: `npm run dev:client`
* Server: `npm run dev:server`
